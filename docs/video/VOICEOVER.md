## Recording tips

1. Play `docs/video/carbonpass-demo.mp4` in QuickTime or VLC with the SRT loaded (VLC: Subtitle → Add Subtitle File) and read along once as a rehearsal.
2. Record the voice in one take while the video plays (QuickTime → File → New Audio Recording, or Audacity). Leave about one second of silence at the very start, then trim it so speech starts at 0:00.
3. Mux it (below). Keep the video exactly as is; the audio is padded with silence to the video's length.

## Mux the voiceover

```bash
node tools/recorder/mux.mjs path/to/voiceover.m4a
```

That writes `docs/video/carbonpass-demo-vo.mp4`. No time to record? `node tools/recorder/tts.mjs` makes a draft with macOS text-to-speech (`docs/video/carbonpass-demo-tts.mp4`). The equivalent raw ffmpeg command for muxing your own recording:

```bash
ffmpeg -i docs/video/carbonpass-demo.mp4 -i path/to/voiceover.m4a -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -af apad -shortest -movflags +faststart docs/video/carbonpass-demo-vo.mp4
```

If ffmpeg fails with `Library not loaded: …libx265…dylib` (a broken Homebrew upgrade), prefix it with `DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/Cellar/x265/4.2/lib` or just use `mux.mjs`, which does that for you.
